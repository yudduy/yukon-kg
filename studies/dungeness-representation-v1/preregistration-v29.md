# Version 29 Preregistration: Controlled Cross-Task Histories

Version 29 adds two treatment-blind, deterministic histories for each of the
two pinned AutoLab tasks. These are controlled parameter sweeps, not agent-
generated narratives. Every event is an executable candidate with one recorded
intervention, an exact source diff, and an outcome from the original verifier.

Toy ISA history A changes the length of a two-way, dual-accumulator scheduled
prefix. History B changes a three-way multiply-accumulate prefix. VLIW history
A changes how many independent ALU/MEM operations share a bundle. History B
changes how many ten-chain groups are interleaved. Frozen parameter orders
contain an improvement, a regression, and a later recovery so R2's unresolved-
comparison rules receive real mixed outcomes.

Calibration is apparatus evidence only. The frozen plans contain the exact
candidate file hashes and expected scores. Qualification must rebuild the
original bundle images and independently replay all 20 plan events, including
the duplicated baseline check for each independent history. Every score must
match exactly. The four ending candidates must materialize under
`users/bx/v29`, resolve through Dungeness's normal candidate-artifact loader,
and retain more than one meaningful gain of reference headroom.

Each trusted export must contain exactly four events and four recorded
interventions. Each window must compile twice with byte-identical results,
equal atom bytes across R0/R1/R2, no post-cutoff event, at most 32,000 total
tokens, and at most 4,000 index tokens. Failure of any candidate, artifact, or
view rejects the affected task and keeps all paid treatments locked.
