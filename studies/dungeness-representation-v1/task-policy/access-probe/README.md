## Status

The paid v1 probe is **inadmissible**. It stopped after five completed sessions and `$0.47631572` total direct spend when a provider transport failure exhausted the frozen retry policy. Before that stop, its first pointer-control session recovered the target evidence but failed strict scoring because the prompt did not expose the scorer's literal enum values. Four treatment sessions failed for the same output-contract reason. These rows are retained in [`v1-results.json`](v1-results.json) as apparatus evidence only; they are not representation outcomes.

V2 repairs only that pre-treatment assay defect, uses six fresh cases, retains the same representations, source atoms, query interface, budgets, models, and gates, and exposes an exact one-match JSON contract. No v1 response is reused.

V2 is complete. Flat joined attempts scored **11/12** versus raw **0/12**; flat-plus-brief scored **11/12** and the pointer control **12/12**. Flat reduced mean calls from 11.17 to 4.92 and returned bytes from 20,828 to 11,668. See the [final v2 report](v2-results.md).

The model-free mechanism gate is complete. No v4 Atlas treatment result exists: its latest preflight stopped before model contact because 9 of 30 reviewed cases failed conservative reachability.

The admitted finite court contains 21 cases reachable in every representation under 11 calls and 22,528 returned bytes. Its deterministic, target-aware traversal result is:

Flat used fewer calls than raw in 21/21 paired cases. It returned more bytes in 20/21. Brief tied flat in 21/21 because the shortest exact-receipt paths never needed the aggregate brief.

The immutable analysis is [`model-free-v1.json`](model-free-v1.json), SHA-256 `ab3233bf270a180665667ceb15fefc2112e18210accd8e971d43f04314060994`.

## Interpretation

This establishes a mechanism, not an agent-performance effect:

- exact duplicate lookup can be **call-bound**, favoring a joined row;
- the same lookup can be **byte-bound**, favoring smaller raw responses;
- an aggregate brief has no reason to help when the answer is one exact receipt.

The automatic path is fixed and target-aware, so it is not a model and is not proof of the globally shortest possible path. The cases are a reviewed finite court, not a random population sample.
